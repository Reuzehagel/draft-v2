Draft

A minimal, snappy Windows push-to-talk speech-to-text app with local (Parakeet v3) and cloud backends, written in Rust.
2026-05-22 · Windows-only v1 · MIT · personal tool

Assumptions baked in

  • Windows 10/11 only for v1. macOS/Linux ports are explicitly deferred.
  • Single user, single machine. No sync, no accounts, no telemetry.
  • The user accepts a ~670MB local model download or supplies a cloud API key.
  • Unsigned binary is acceptable (personal use; SmartScreen warning ignored).
  • Repo stays private until launch; no CI workflow files committed yet.

Data flow

  1. Boot — main.rs acquires named mutex Draft.SingleInstance. If already held, send "open settings" on the named pipe and exit.
  2. Init — load config.toml, init tracing file appender, build tray icon, register global hotkey via global-hotkey. Mic is not opened yet.
  3. Hotkey press — HotKeyEvent { state: Pressed } arrives on the global-hotkey receiver. Forward to AppEvent::HotkeyPressed { ts } on the app channel.
  4. Activation FSM — activation::Fsm consumes HotkeyPressed/HotkeyReleased, applies the configured mode (Hold / Toggle / Hold-with-double-press-lock), emits SessionEvent::Start / SessionEvent::Stop.
  5. Start — spawn audio::Capture: open cpal stream at device-native rate, resample to 16 kHz mono f32 in the cpal callback, push samples into a growable ring buffer. Open pill window, fade-in 120ms.
  6. Live frame loop — pill's render thread reads the last ~50ms of samples each frame, computes 16-band RMS (cheap FFT or sub-band split), redraws via tiny-skia. Recording time gate: hard cap 10 min.
  7. Stop — SessionEvent::Stop closes the cpal stream, takes the full PCM buffer. If duration < 150ms, drop it and silent-fade the pill. Otherwise transition pill to loading state.
  8. Transcribe — call the active Transcriber::transcribe(samples). For local: transcribe-rs ParakeetModel via ort with DirectML EP if available, else CPU. For cloud: HTTP POST multipart to the provider, await JSON, extract text.
  9. Post-process — strip outer whitespace, collapse \n to space, optionally append trailing space. Empty result ⇒ silent fade-out.
  10. Inject — arboard: read & stash current clipboard, set transcript, send Ctrl+V via enigo, wait ~80ms, restore previous clipboard if configured.
  11. Finish — pill goes to success state (green outline + check), dwell 600ms, fade out.
  12. Errors at any stage → SessionEvent::Error(reason), pill shows red-outline state 1500ms, error string saved to tray tooltip "Last error: …" and to app.log.

Key code

The Transcriber trait

Single point of polymorphism between local and cloud backends. Async so cloud calls don't block; local impl returns ready future after blocking work on a worker thread.

// src/transcribe/mod.rs
use anyhow::Result;
use async_trait::async_trait;

#[derive(Clone, Debug)]
pub struct TranscribeRequest<'a> {
    pub samples: &'a [f32],
    pub sample_rate: u32,    // always 16_000 in v1
}

#[derive(Clone, Debug, Default)]
pub struct TranscribeOutput {
    pub text: String,
    pub language: Option<String>,
}

#[async_trait]
pub trait Transcriber: Send + Sync {
    fn name(&self) -> &'static str;
    async fn transcribe(&self, req: TranscribeRequest<'_>) -> Result<TranscribeOutput>;
}

Local backend (transcribe-rs adapter)

Holds the loaded ParakeetModel. spawn_blocking keeps the async runtime unblocked during the ORT call.

// src/transcribe/local.rs
use transcribe_rs::{SpeechModel, parakeet::{ParakeetModel, ParakeetParams}};
use std::sync::Arc;
use tokio::sync::Mutex;

pub struct LocalParakeet {
    inner: Arc<Mutex<ParakeetModel>>,
}

impl LocalParakeet {
    pub fn load(weights_dir: &std::path::Path) -> anyhow::Result<Self> {
        let m = ParakeetModel::load_from_dir(weights_dir)?; // exact API per transcribe-rs 0.3.x
        Ok(Self { inner: Arc::new(Mutex::new(m)) })
    }
}

#[async_trait::async_trait]
impl super::Transcriber for LocalParakeet {
    fn name(&self) -> &'static str { "parakeet-v3-local" }

    async fn transcribe(&self, req: super::TranscribeRequest<'_>) -> anyhow::Result<super::TranscribeOutput> {
        let samples = req.samples.to_vec();
        let model = self.inner.clone();
        let out = tokio::task::spawn_blocking(move || -> anyhow::Result<String> {
            let mut m = model.blocking_lock();
            let segments = m.transcribe_with(&samples, &ParakeetParams::default())?;
            Ok(segments.into_iter().map(|s| s.text).collect::<Vec<_>>().join(" "))
        }).await??;
        Ok(super::TranscribeOutput { text: out, language: None })
    }
}

Activation FSM

The trickiest piece. Same input events, three modes, plus the optional "double-press locks toggle while held" behavior.

// src/activation.rs
use std::time::{Duration, Instant};

#[derive(Copy, Clone, Debug)]
pub enum Mode {
    Hold { double_press_lock: bool },
    Toggle,
}

#[derive(Debug)]
pub enum InEvent { Pressed(Instant), Released(Instant) }

#[derive(Debug, PartialEq)]
pub enum OutEvent { Start, Stop, Ignore }

pub struct Fsm {
    mode: Mode,
    recording: bool,
    locked: bool,                    // only meaningful for Hold + double_press_lock
    last_press: Option<Instant>,
    busy_until: Option<Instant>,     // ignore presses during loading
    dbl_window: Duration,
}

impl Fsm {
    pub fn new(mode: Mode) -> Self {
        Self { mode, recording: false, locked: false,
               last_press: None, busy_until: None,
               dbl_window: Duration::from_millis(300) }
    }

    pub fn mark_busy(&mut self, until: Instant) { self.busy_until = Some(until); }

    pub fn step(&mut self, ev: InEvent) -> OutEvent {
        let now = match ev { InEvent::Pressed(t) | InEvent::Released(t) => t };
        if matches!(self.busy_until, Some(t) if now < t) { return OutEvent::Ignore; }

        match (self.mode, ev) {
            (Mode::Toggle, InEvent::Pressed(_)) => {
                self.recording = !self.recording;
                if self.recording { OutEvent::Start } else { OutEvent::Stop }
            }
            (Mode::Toggle, InEvent::Released(_)) => OutEvent::Ignore,

            (Mode::Hold { double_press_lock }, InEvent::Pressed(t)) => {
                let is_double = double_press_lock
                    && self.last_press.map_or(false, |p| t.duration_since(p) <= self.dbl_window);
                self.last_press = Some(t);
                if self.locked {
                    self.locked = false; self.recording = false; OutEvent::Stop
                } else if is_double {
                    self.locked = true;
                    if self.recording { OutEvent::Ignore }
                    else { self.recording = true; OutEvent::Start }
                } else if !self.recording {
                    self.recording = true; OutEvent::Start
                } else { OutEvent::Ignore }
            }
            (Mode::Hold { .. }, InEvent::Released(_)) => {
                if self.locked { OutEvent::Ignore }
                else if self.recording { self.recording = false; OutEvent::Stop }
                else { OutEvent::Ignore }
            }
        }
    }
}

Audio capture → ring buffer

cpal callback runs on the audio thread; never block, never allocate inside it. Resample to 16k via a fixed cubic-interpolation step; for simple ratios rubato is overkill, but it is the safe choice if accuracy matters.

// src/audio/capture.rs (sketch)
use cpal::traits::{DeviceTrait, HostTrait, StreamTrait};
use std::sync::{Arc, Mutex};

pub struct Capture {
    _stream: cpal::Stream,
    pub ring: Arc<Mutex<Vec<f32>>>,   // grown, capped at 10 min worth
}

const TARGET_SR: u32 = 16_000;
const MAX_SECONDS: usize = 10 * 60;
const MAX_SAMPLES: usize = TARGET_SR as usize * MAX_SECONDS;

impl Capture {
    pub fn start() -> anyhow::Result<Self> {
        let host = cpal::default_host();
        let dev  = host.default_input_device().ok_or_else(|| anyhow::anyhow!("no input device"))?;
        let cfg  = dev.default_input_config()?;
        let device_sr = cfg.sample_rate().0;
        let channels  = cfg.channels() as usize;

        let ring = Arc::new(Mutex::new(Vec::with_capacity(TARGET_SR as usize * 5)));
        let ring_cb = ring.clone();
        let mut resampler = SimpleResampler::new(device_sr, TARGET_SR);

        let stream = dev.build_input_stream(
            &cfg.config(),
            move |data: &[f32], _| {
                // 1. downmix to mono
                let mono: Vec<f32> = data.chunks(channels)
                    .map(|f| f.iter().copied().sum::<f32>() / channels as f32)
                    .collect();
                // 2. resample to 16k
                let out = resampler.process(&mono);
                // 3. append (drop oldest if at cap)
                let mut r = ring_cb.lock().unwrap();
                let new_len = r.len() + out.len();
                if new_len > MAX_SAMPLES {
                    let overflow = new_len - MAX_SAMPLES;
                    r.drain(..overflow);
                }
                r.extend_from_slice(&out);
            },
            |err| tracing::error!(?err, "cpal stream error"),
            None,
        )?;
        stream.play()?;
        Ok(Self { _stream: stream, ring })
    }

    pub fn take(self) -> Vec<f32> {
        let mut r = self.ring.lock().unwrap();
        std::mem::take(&mut *r)
    }
}

Clipboard paste flow

// src/inject.rs
use arboard::Clipboard;
use enigo::{Enigo, Key, KeyboardControllable};
use std::{thread, time::Duration};

pub fn paste(text: &str, restore_previous: bool) -> anyhow::Result<()> {
    let mut cb = Clipboard::new()?;
    let prev = if restore_previous { cb.get_text().ok() } else { None };

    cb.set_text(text.to_string())?;
    thread::sleep(Duration::from_millis(20)); // let clipboard settle

    let mut e = Enigo::new();
    e.key_down(Key::Control);
    e.key_click(Key::Layout('v'));
    e.key_up(Key::Control);

    if let Some(p) = prev {
        thread::sleep(Duration::from_millis(80)); // let destination consume the paste first
        let _ = cb.set_text(p);
    }
    Ok(())
}

Pill state & render loop spine

// src/pill/anim.rs
#[derive(Copy, Clone, Debug, PartialEq)]
pub enum PillState {
    Hidden,
    FadeIn   { t0: std::time::Instant }, // 120ms
    Recording,
    Loading,
    Success  { t0: std::time::Instant }, // 600ms dwell, then FadeOut
    Error    { t0: std::time::Instant }, // 1500ms dwell
    PasteFallback { t0: std::time::Instant }, // 2000ms dwell
    FadeOut  { t0: std::time::Instant }, // 200ms
}

pub fn ease_out_cubic(x: f32) -> f32 {
    let inv = 1.0 - x.clamp(0.0, 1.0);
    1.0 - inv * inv * inv
}

External resources to pin

  • Model files: istupakov/parakeet-tdt-0.6b-v3-onnx at a fixed revision; record SHA256 of each downloaded file in src/model_dl.rs.
  • ONNX Runtime: pulled transitively by ort via transcribe-rs; pin transcribe-rs = "=0.3.x".
  • DirectML EP: bundled with ORT Windows binary; auto-selected by feature flag ort-directml.

transcribe-rs abandonment (solo maintainer, RC-pinned ORT) Medium High Pin exact version, vendor the crate into a fork the day it stops moving. Fallback: drop to ort directly — reimplement TDT decoding (~2 weeks of work, doable).

cpal stream open latency (30–100ms WASAPI init) clips first word Medium Low Users naturally pause briefly after pressing the key. If complaints arrive, add a 100ms hotkey-arm delay (start stream, then accept "speaking now" signal). Not a v1 fix.
Clipboard paste blocked by destination app (some IDEs, password managers) Medium Medium Detect by re-reading clipboard ~150ms post-paste; if unchanged, surface the "paste fallback" pill state — transcript stays on clipboard for manual paste.
DirectML quirks on certain Intel iGPUs cause ORT init to fail Medium Low Wrap DirectML EP init in std::panic::catch_unwind and fall back to CPU EP silently. Log the failure once.
Hotkey unavailable (RegisterHotKey fails because another app owns the combo) Medium High Detect failure return, show red banner in settings + tray tooltip ("Hotkey unavailable: Ctrl+\\"), block transcription until rebound. Add a "find a free combo" helper.

16k mono resampling at capture is wrong — quality regression vs capturing native + resampling at transcribe time Low Medium Use rubato (sinc-based) rather than naive cubic, even though it costs ~0.5MB binary. Validate WER on a fixed clip set before shipping.

Open questions

Open question: exact transcribe-rs API for loading a Parakeet model directory — the code above uses ParakeetModel::load_from_dir, but 0.3.11 may expose a different constructor (per-file paths for encoder/decoder/joint/vocab). Verify on first compile.
Open question: Reson8 public API stability — if their endpoint is not yet generally available at implementation time, drop from v1 silently; the Transcriber trait makes re-adding it a one-file change.
Open question: resume support for model download. Nice-to-have. Decide based on observed first-run flake rate.

Build order suggestion

  1. Skeleton: main.rs, single-instance, tray icon, log file, config load. Quit via tray works.
  2. Hotkey + activation FSM with stub Start/Stop logs. Verify all three modes by hand.
  3. cpal capture → ring buffer. Hotkey ends with a WAV dumped to %TEMP%\draft-last.wav. Listen to it.
  4. Pill window: winit + tiny-skia. Static black rounded rect with bars at random heights. Click-through verified.
  5. Wire RMS → bar heights. Speak into the mic, watch the bars move.
  6. Cloud transcriber (Groq, simplest). End-to-end: speak, see green pill, see text pasted into Notepad.
  7. Clipboard restore + paste fallback detection.
  8. egui settings window + TOML persistence + keyring.
  9. Model download flow + local Parakeet via transcribe-rs.
  10. First-run wizard, autostart, update check, MSI build.
